# 🚀 个人网站项目

## 📋 项目概述
这是一个个人网站和作品集项目，用于展示个人技能、项目和成就。

## 🎯 项目目标
1. 创建专业的个人在线展示平台
2. 展示技术能力和项目经验
3. 提供联系方式和个人简介
4. 支持博客和内容发布

## 🏗️ 技术栈
- **前端**: HTML5, CSS3, JavaScript
- **框架**: 可选 React/Vue.js
- **样式**: Tailwind CSS / Bootstrap
- **部署**: GitHub Pages
- **工具**: Git, GitHub Actions

## 📁 项目结构
```
personal-website/
├── index.html          # 首页
├── about.html          # 关于页面
├── projects.html       # 项目展示
├── blog/              # 博客目录
├── assets/            # 静态资源
│   ├── css/          # 样式文件
│   ├── js/           # 脚本文件
│   └── images/       # 图片资源
└── README.md          # 项目说明
```

## 🚀 快速开始

### 1. 克隆项目
```bash
git clone https://github.com/brazzey/personal-website.git
cd personal-website
```

### 2. 本地开发
- 使用任何文本编辑器打开项目
- 修改HTML/CSS/JS文件
- 在浏览器中打开index.html预览

### 3. 部署到GitHub Pages
```bash
# 提交更改
git add .
git commit -m "更新内容"
git push origin main

# GitHub Pages会自动部署
```
